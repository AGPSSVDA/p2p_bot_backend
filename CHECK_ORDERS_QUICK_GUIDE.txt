WHAT DOES EACH CRITERIA MEAN?
─────────────────────────────────────────────────────────────────────────────

1. 30-Day Trades
   → पिछले 30 दिनों में कितने trades किए
   Required: 20 का मतलब कम से कम 20 trades होने चाहिए

2. Completion Rate (%)
   → कितने % trades successful रहे
   Required: 98% का मतलब कम से कम 98% trades complete होने चाहिए

3. Avg Release Time
   → औसतन कितने समय में crypto release करता है
   Max: 3 min का मतलब 3 मिनट से कम में release करना चाहिए

4. Avg Pay Time
   → औसतन कितने समय में payment करता है
   Max: 15 min का मतलब 15 मिनट से कम में payment करना चाहिए

5. Registered Days
   → Account कितने दिन पुराना है
   Required: 100 का मतलब कम से कम 100 दिन पुराना होना चाहिए

6. Trading Counterparties
   → कितने अलग-अलग लोगों के साथ trade किया
   Required: 50 का मतलब कम से कम 50 अलग लोगों के साथ होना चाहिए

7. All Trades Count
   → कुल कितने trades किए हैं
   Required: 100 का मतलब कम से कम 100 trades होने चाहिए

8. Buy Orders Count
   → कितने buying orders किए हैं
   Required: 75 का मतलब कम से कम 75 buy orders होने चाहिए

9. Sell Orders Count
   → कितने selling orders किए हैं
   Required: 25 का मतलब कम से कम 25 sell orders होने चाहिए

10. First Trade Days
    → पहले trade के बाद से कितने दिन हुए
    Required: 100 का मतलब पहले trade के बाद से 100+ दिन होने चाहिए

WHAT HAPPENS WHEN ORDER IS PLACED?
─────────────────────────────────────────────────────────────────────────────

Timeline:

1. MINUTE 0
   → Buyer Binance पर आपके AD पर order place करता है

2. MINUTE 0-1
   → Polling system Binance से नया order check करता है
   → Order database में save होता है

3. MINUTE 1-2
   → Buyer की Binance profile से metrics fetch होते हैं
   → Database में metrics save होते हैं

4. MINUTE 2-3
   → Eligibility check automatically run होता है
   → Pass/Fail status database में save होता है

5. MINUTE 3+
   → आप terminal पर या frontend पर check कर सकते हैं
   → सभी details दिख जाएंगी

DATABASE COLUMNS (Advanced Users)
─────────────────────────────────────────────────────────────────────────────

seller_orders table में:
  • order_number: Order का unique ID
  • buyer_id: Buyer का Binance ID
  • buyer_nickname: Buyer का नाम
  • ad_no: जिस AD पर order है
  • eligibility_check_passed: 1=Pass, 0=Fail, NULL=Pending
  • eligibility_check_completed_at: Check कब run हुआ
  • eligibility_check_failed_reason: अगर fail तो क्यों fail हुआ

seller_buyer_metrics table में:
  • buyer_id: Buyer का Binance ID
  • trades_30day: पिछले 30 दिनों में कितने trades
  • completion_rate_30day: कितने % complete हुए
  • registered_days: Account कितने दिन पुराना है
  • trading_counterparty_count: कितने लोगों के साथ trade किया
  • all_trades_count: कुल trades की संख्या
  • buy_orders_count: कितने buy orders किए
  • sell_orders_count: कितने sell orders किए
  • avg_release_time_minutes: औसत release time
  • avg_pay_time_minutes: औसत pay time

TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

Q: Terminal में "No orders found" क्यों दिख रहा है?
A: अभी कोई भी real order place नहीं हुआ। जब कोई order आएगा तो दिखेगा।

Q: "Buyer metrics not found" क्यों?
A: Order अभी database में sync नहीं हुआ या metrics fetch नहीं हुए।
   2-3 मिनट रुकें और फिर से try करें।

Q: Frontend पर modal नहीं खुल रहा?
A: Server check करें: npm start चल रहा है?
   Database में order है?
   Buyer metrics save हैं?

Q: Eligibility status "PENDING" क्यों है?
A: Check अभी run नहीं हुआ। Polling को समय दें (5-10 सेकंड)।
