================================================================================
QUICK REFERENCE - What Each Log Means
================================================================================

🔵 [SELLER SYNC]          → Main sync controller
🔵 [SELLER BINANCE]       → Binance API service
🔵 [SELLER STATUS]        → Status check endpoint

✅ = Success/Completed
❌ = Error/Failed
🔄 = Processing
📡 = Network request
💾 = Database operation
📦 = Data received
📋 = List/Details
🎉 = Sync finished
⏭️  = Skipped
📍 = Configuration
🔐 = Authentication

================================================================================
HOW TO USE LOGS
================================================================================

1. Start backend with logs visible:
   npm start 2>&1 | tee sync.log

2. Trigger sync:
   Click "Sync from Binance" in UI
   OR
   curl -X POST http://localhost:5000/api/seller/sync/ads \
     -H "Authorization: Bearer YOUR_TOKEN"

3. Watch terminal for logs

4. If error, find the ❌ line and see what failed

5. Check the "FIX:" section above for solution
